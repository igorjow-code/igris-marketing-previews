# IGRIS MARKETING — previews

Sites de demonstração gerados pelo IGRIS MARKETING para prospecção — um por negócio-alvo,
em `/<slug>/`. Publicados aqui só pra virar link (GitHub Pages), sem domínio próprio, com
`noindex` em todo site. Não é o site oficial de nenhum negócio listado — é uma prévia
independente, mostrada antes de virar cliente pagante.

## Sites

- [`vivian-melo/`](vivian-melo/) — Vivian Melo, consultora de imagem e estilo (Feira de Santana, BA), 18/11/2026. Fotos e vídeos cedidos pela cliente.
- [`uniao-motors/`](uniao-motors/) — União Motors, seminovos (Feira de Santana, BA), 26/11/2026. Proposta ainda não apresentada à loja; cenas do pátio e do showroom geradas por IA.

## Como isso funciona

Cada pasta é estática (HTML/CSS/JS puro, sem build). O gerador vive no repositório privado
`igris-os`, em `projetos/igris-marketing/`.
